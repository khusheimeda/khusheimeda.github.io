Multi-Goal Delivery Robot with Dynamic Replanning

Github

ROS1, Gazebo, RViz, Python

  • Implemented an end-to-end ROS1 delivery stack on an omnidirectional Triton robot that maps an indoor space, plans paths with A*, and visits multiple drop-off locations in an efficient order.
  • Applied LiDAR-based obstacle checks and on-the-fly replanning so the robot stops and reroutes when its path is blocked, then continues the remaining deliveries.
