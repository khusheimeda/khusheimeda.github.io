Autonomous Robot Wall Following

Github

ROS1, Gazebo, Python

  • Implemented Q-Learning and SARSA in ROS1 with custom state representations from 2D LiDAR sensor data and reward functions to optimize Triton robot navigation in Gazebo simulation.
  • Applied epsilon-greedy exploration with Temporal Difference learning to iteratively update Q-values, enabling the robot to generalize the learned policy across five distinct wall-following scenarios.
